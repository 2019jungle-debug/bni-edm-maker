# BNI 富鼎分會 · 個人 EDM 即時製作工具

會員可即時填寫並下載個人化 EDM（PNG）圖檔。純靜態網頁，可直接用 GitHub Pages 上架。

## 功能
- 形象照上傳、姓名、職稱、專業別（內建富鼎分會第16屆完整清單）
- EDM 主標／副標 Slogan
- 合作對象、一般／理想／夢幻引薦（各 3 項）
- 代表性客戶（3 家）、獨特銷售主張 (USP)
- 右側即時預覽，一鍵下載高解析 PNG
- 內容自動存在瀏覽器，下次打開自動帶入

## 本機開啟
直接用瀏覽器打開 `index.html` 即可。

## 檔案
- `index.html` — 版面與表單
- `app.js` — 互動邏輯、下載、自動儲存
- `specialties.js` — 富鼎分會專業別清單

## 登入與作品查看（2026-09-10 更新）
- 所有非管理者會員統一使用 `888888`，不需輸入姓名，登入後從會員下拉選單選擇要編輯的會員。既有組別密碼不再用於登入，新會員不需另外設定密碼。
- 管理者仍輸入 `A` 後使用原有管理者密碼。
- 所有人（含訪客）可在會員下拉選單或名冊的「檢視 EDM」查看任何會員作品。
- 會員可編輯並儲存所有會員資料；管理者可管理全部會員。登入僅提供前端防誤改保護。
- 網站右上「使用說明」提供會員與管理者操作步驟。
